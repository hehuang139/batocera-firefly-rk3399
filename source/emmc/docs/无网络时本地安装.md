# 无网络时使用本地键盘安装

TF 安装卡已内置完整 eMMC 固件，实际写入不需要联网。SSH 只是电脑操作板上终端的一种入口。

安装卡进入 Batocera 后，接 USB 键盘，尝试按 **Ctrl + Alt + F5** 切换到文本登录终端。系统的 `/etc/inittab` 已配置 tty5 的 getty。用户名 `root`、默认密码 `linux`，登录后使用与 SSH 相同的命令：

```sh
python3 /boot/emmc/install-to-emmc.py
```

确认检查通过，再按安装说明选择备份选项。已备份所需数据并接受覆盖原系统时：

```sh
python3 /boot/emmc/install-to-emmc.py --write --no-backup
```

看到 `INSTALL PASS` 后 `poweroff`，关机断电再拔 TF，重新上电进入 eMMC 系统。

如果快捷键没有出现文本登录，保留 HDMI 画面信息，使用有线网络的 SSH 入口排查。不要切换到 tty4；该终端被系统用作音量调整界面。
