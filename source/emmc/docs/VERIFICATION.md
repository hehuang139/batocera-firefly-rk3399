# eMMC 版验证记录

环境为 Linux x86_64，Ubuntu 22.04 构建容器，GCC 11.4。目标原版 Firefly-RK3399 DDR3。

- 引导程序：42项实际产物检查，DDR3、eMMC SPL、TF救援优先的U-Boot目标、52MHz启动模式、无持久环境及FIT/ELF内容。
- 设备树：39项检查，eMMC控制器/PHY启用、HS200及8位1.8V、Linux固定mmc2；与TF版只有6项存储相关属性差异，其余2115项保持一致。两次DTB哈希一致。
- 安装程序：38项离线行为测试，涵盖目标板型/类型/容量、运行介质、挂载/交换区/设备映射、镜像校验、备份、分段写入、完整回读、旧GPT尾部清理及失败处理。测试使用临时普通文件。
- 独立检查：默认只读命令拒绝在当前非板卡环境中运行；3项控制流夹具确认默认路径不会进入卸载/打开写设备/备份/写入。
- 重建脚本：22项夹具检查，包括固定输入校验、拒绝覆盖、manifest一致性与两份最终验证器调用。
- 成品：独立整盘验证器分别读取eMMC镜像和TF安装镜像，检查分区、实际启动字节、设备树、根参数、内核/initrd/SquashFS/SHARE哈希和gzip完整解压；安装卡内的eMMC固件也再次读出并核对压缩/解压哈希。实际计数见发行目录validation报告。

eMMC镜像和安装卡继承已完成逐文件核对的系统负载；此次不重新压缩SquashFS。原TF版的46,805个保留普通文件内容与官方基底一致，5个计划修改和1个新增配置分别记录在原报告中。

首次实板步骤：TF安装卡启动、实际eMMC写入与完整读回、拔TF独立启动、HDMI音画、手柄、网络与重启。板上安装器成功报告保存于TF的 `/userdata/system/logs/emmc-install-时间.json`。
